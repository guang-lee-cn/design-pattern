读法（三个反直觉点）：

1. **§4 是全场最极端的倒挂**：149 个中文字配 107 行代码——它几乎不是一"章"，而是一组代码标本。log 说"§4 三工厂对比好"，实际起作用的是 §4.5 那一张表，不是这一章的论述。
2. **§10 比大多数正文章节还长**：278 字的"待展开清单"，长过 §3（259）、§4（149）、§5（206）、§6（187）。**将来要写什么，比已经写了什么更占篇幅**——这正是"素材是地图不是手册"的量化证据。
3. **§9 论述最多（673）但摊到 6 个项目**，每个项目仅 112 字，是全系列最难写的一篇。

## 图 13 · 组合根 + 注册表装配时序

第 3 篇的支付渠道 demo，也解释了为什么"自注册"会付出调试代价：

```mermaid
%%{init: {'theme':'base','themeVariables':{'primaryColor':'#e8f3ee','primaryTextColor':'#1f2b36','primaryBorderColor':'#0e6b52','lineColor':'#8496a5','actorBkg':'#e8f3ee','actorBorder':'#0e6b52','fontFamily':'Microsoft YaHei'}}}%%
sequenceDiagram
    participant SP as 各工厂 .cpp 静态初始化
    participant Reg as PaymentFactoryRegistry
    participant CR as 组合根 main
    participant OS as OrderService
    Note over SP,Reg: 启动阶段，无人显式调用
    SP->>Reg: registerFactory 登记 支付宝 / 微信 / 银联
    Note over CR: 启动完成，注册表已就绪
    CR->>Reg: create 按配置取工厂
    Reg-->>CR: 返回抽象产品 unique_ptr
    CR->>OS: 构造注入（不是服务定位）
    Note over OS: 业务代码只认抽象接口
```

**代价就在这里**：注册发生在"无人显式调用"的静态初始化阶段，所以 MSVC + 静态库下会被链接器裁掉——这个坑必须写进第 4 篇的踩坑清单。
