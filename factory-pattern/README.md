# factory-pattern · C++ 工厂模式

> 创建型模式 · **按知识骨架推进，不按篇数规划**

## 从哪读起

| 入口 | 内容 |
|---|---|
| [`docs/`](docs/) | 正文（markdown + 内嵌 Mermaid），一篇文章一个文件 |
| [`code/`](code/) | 配套 C++ 工程，随篇章增量增长，可独立编译 |
| [`notes/`](notes/) | 写作过程中的问题记录与复盘 |

知识骨架、节的依赖顺序、体例要求见仓库根 [`TEMPLATE.md`](../TEMPLATE.md)。
素材来源与写作排期在仓库外，不随本仓库发布。

## 按骨架推进

一个**节**是知识单元，一篇**文**是阅读单元：一节可以写成一篇文章，也可以拆成几篇；
反过来不行——篇的划分服从节的划分。

| # | 节 | 状态 | 落地形态 |
|---|---|---|---|
| 1 | 是什么 | ✅ 已展开 | [`docs/01-工厂模式是什么.md`](docs/01-工厂模式是什么.md) |
| 2 | 背景与代价 | ⏸️ 已标记未展开 | — |
| 3 | 分类与层次 | ⏸️ 已标记未展开 | — |
| 4 | 代码对比 | ⏸️ 已标记未展开 | — |
| 5 | 业务场景 | ⏸️ 已标记未展开 | — |
| 6 | 上层结构 | ⏸️ 已标记未展开 | — |
| 7 | 语言演进 | ⏸️ 已标记未展开 | — |
| 8 | 与相邻概念的边界 | ⏸️ 已标记未展开 | — |
| 9 | 真实项目案例 | ⏸️ 已标记未展开 | — |
| 10 | 待展开清单 | ⏸️ 已标记未展开 | — |

状态口径：`✅` = 正文写了、代码进了 `code/`、验证跑过（三条齐了才算）；
`⏸️` = 知道要写什么但还没写；`⬜` = 知道缺东西但还不知道缺什么。

进度表按**节**记而不按篇记：按篇排的表在第一次返工重排章节时就会作废，
按节排的不会——节的划分服从知识依赖，不服从排版。

## 编译

```bash
cd code
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

当前 `code/` 只有构建骨架：第 1 篇是概念章，不含可编译对照。
「背景与代价」一节会引入第一份对照工程——那是骨架里要求"必须有可编译对照"的第一节。
