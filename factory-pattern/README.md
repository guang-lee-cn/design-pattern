# 工厂模式（Factory Pattern）

C++ 学习与实战子项目。**17 篇正文 + 13 个可运行场景**，编排见 [`docs/00-讲解计划.md`](docs/00-讲解计划.md)。

## 目录约定

```
factory-pattern/
├── docs/              正文 17 篇：主线 8（含 08 MVP 沉淀）+ 子专题 2（04a/04b）+ 专题 6（A01~A06）+ 检验 1
│   └── assets/        手写 SVG 具象图 17 张 + GIF 动图 3 张
├── code/              13 个自包含场景目录，各自带构建入口（build.sh / Makefile）
└── notes/             问题记录与复盘（可选：真踩过坑才建，当前未建）
```

`docs/` 三层命名：主线 `NN-`（子编号写 `04a-`）、专题 `A0N-`、检验 `quizNN-`。

## 图例体例

- **具象图**（内存布局 / 时序 / 指针关系 / 对象状态）→ 手写 SVG，存 `docs/assets/`，
  正文用 `![](assets/xxx.svg)` 引用；
- **过程**（多拍推进）→ GIF 动图。**静态矢量版必须同时保留**：GIF 首帧只含第一拍，
  降级不安全（不播的平台会丢掉后几拍）；
- 两种配法别混：① **同源两形态**（如 07）——一个脚本同时出 SVG 与 GIF；
  ② **两张不同切面**（如 A06 / 06）——静图＝并置差异、动图＝过程推进，是两张独立的图。
