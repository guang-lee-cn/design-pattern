贯穿全系列的约束

  • 共享一个可编译 repo。第 1 篇建骨架与 CMake，之后每篇只增 NN_xxx/main.cpp：cmake -B build && cmake --build build && ctest 一键跑通，编译器矩阵 GCC 11+ / Clang 14+ / MSVC 19.3+。
  • 开篇声明边界（放在第 1 篇章首，不单独写导读篇）：本系列讲创建与装配的职责划分，不覆盖线程安全、异常安全、ABI 兼容；测试只演示"替换实现"。
  • 每篇结尾做下篇预告，且预告项必须在上表内有归属——不留无主之坑。
  • 每篇图 ≥ 1 张，且优先补对比类图（演化关系 / 依赖变化 / 决策树），而非再补结构图。
  • 所有代码必须能编译：正文代码块与 repo 文件同名同序。注意静态库 + MSVC 下自注册会被链接器裁剪，第 3、4 篇用 OBJECT 库兜底。
